# Sentiment Aware Chatbot

A full-stack emotion-aware chatbot that detects user sentiment and generates context-aware, empathetic responses.

## Project Structure
- `client/` - React frontend
- `server/` - Flask backend
- `training/` - model training and evaluation scripts
- `data/` - dataset files

## Tech Stack
- React
- Flask
- Transformers
- Gemini API
- Python
